# Pilario 2.2.0

Pilario es una aplicación de gestión sencilla para profesionales de Pilates.

## Novedades
- Marca genérica Pilario y logotipo provisional.
- Espacio personalizable por instructor: nombre, estudio, colores y logotipo.
- Saludo personalizado.
- Sincronización manual, acceso directo a la hoja y desconexión de Google Drive.
- Reconexión más cómoda después de actualizar la página.
- Archivo de datos Pilario - Datos con migración automática del archivo anterior.
- Acceso beta restringido mediante usuarios de prueba de Google y formulario de solicitud.

- Nuevo filtro **Preparación** para agrupar ejercicios que comparten montaje: caja larga, caja corta, correas, bandas, tabla de salto o ajustes de muelles.

- Las asistencias del alumno abren la clase concreta con valoración y comentarios.
- Nueva vista de estadísticas por semana y resumen de las últimas ocho semanas.
- Restablecimiento seguro: el archivo actual se archiva y se crea un nuevo `Pilario - Datos`.
